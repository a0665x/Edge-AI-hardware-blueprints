人流與越線

商店入口：偵測行人、關聯 ID，依方向統計越線。 以事件召回率與每小時誤報驗收；遮擋、逆光與交叉動線需要真實影片。追蹤 ID 不等於身分辨識。 技術起點：相機 → YOLO → ByteTrack → 越線事件。驗收：越線事件召回、每小時誤報、遮擋／交叉 ID、P95 與掉幀。

定點外觀檢查

產線工件停止或觸發曝光後，找出缺陷位置並標記待複檢。 靜態不代表不即時：節拍仍有 deadline。缺陷太小時，先改善光學、打光或分塊，不能只提高 TOPS。 技術起點：觸發曝光 → ROI → 偵測／分割 → 複檢。驗收：最小缺陷 px、漏檢與誤剔除率、打光變化、觸發至結果與產線節拍。

文件與儀表

設備旁的讀表終端：拍攝、校正、辨識數值，再驗證格式。 OCR 作為預設起點；只有遇到開放語意或複雜版面才加 VLM。驗收單位是欄位正確率與錯誤處置。 技術起點：取像 → 透視校正 → OCR → 規則驗證。驗收：各欄位正確率、字元 px、反光／斜角、格式失敗與重拍處置。

表面特徵點追蹤

工作台上的軟質物件：使用者點選表面特徵，追蹤位置與遮擋狀態。 TAPNet 是專案系列；此處起測選 causal TAPIR。高 FPS 有助降低幀間位移，但不是所有點追蹤的固定要求。須定義速度、特徵大小、遮擋與點數。 技術起點：曝光 → 特徵點 → 線上追蹤 → 軌跡。驗收：點誤差／可見性、特徵 px、幀間位移、遮擋恢復、state 峰值與 P95。

空間與距離

倉庫走道：估計前景與背景關係，提示可能的近距離障礙。 相對深度不等於公尺。若要距離精度與避障驗收，需度量模型、標定及感測器對照；不可直接作安全認證。 技術起點：影像 → Depth Anything → 尺度校正 → 距離判斷。驗收：relative 排序與 metric 誤差分開；近遠距 ground truth、尺度漂移、透明反光失效。

影片物件遮罩

錄影檢閱：圈選一個物件，傳播遮罩並讓人員修正。 離線可用時間換品質；直播需檢查串流記憶體、重初始化、遮擋與端到端延遲。 技術起點：影片 → 提示 → SAM 2 → 遮罩修正。驗收：IoU／邊界、遮擋、重新提示率、每片段時間與 memory state。

事件語意判讀

工廠巡檢：偵測候選事件後，抽取關鍵影格，判讀是否需要人工處置。 VLM 放在慢速語意路徑；快速告警走確定性規則。回答需限制格式、拒答機制與誤判驗收。 技術起點：輕量偵測 → 事件取樣 → VLM → 人工／規則。驗收：事件召回、語意誤判、拒答、schema 正確率、突發事件排隊與 VLM P95。

移動機器人避障

倉庫 AMR 遇到低矮物件，融合深度與里程資料，在可用距離內減速或停止。 要分段定義近／遠距誤差、最小障礙物、反光與低紋理失效模式；相對深度不能直接輸出可靠公尺。AI 與安全控制需分開驗收。 技術起點：Stereo / ToF → 深度校正 → 障礙物 → 控制器。驗收：分段公尺誤差、低矮物件、煞停範圍、反光／低紋理與控制故障處置。

雲台／移動相機追蹤

巡檢相機跟著目標轉動，先處理相機自轉與滾動快門，再追蹤表面特徵。 目標運動與相機運動須分開；gimbal 不代表完全無晃動。FOV、角速度、曝光與 timestamp 誤差都會改變輸入。 技術起點：相機 + IMU → 時間同步 → 穩定 / 補償 → 追蹤。驗收：角速度、FOV、IMU timestamp 誤差、補償殘差、快門讀出與追蹤恢復。

本地語音 Agent

維修人員詢問設備故障；本機檢索手冊，Agent 準備工具操作並由人員確認。 500 ms 先定義成首個音訊還是完整回覆。模型、量化、context、prefill、endpointing、噪音與回音消除都需指定。預設參考 Strata 的 Qwen3.8 路徑。 技術起點：VAD / ASR → 本地 LLM + RAG → 工具確認 → 串流 TTS。驗收：WER、VAD endpoint、首音訊／完整回答 P95、AEC、barge-in、長 context 和並發峰值。

文件知識／工具 Agent

工業終端回答維修問題，檢索本地文件並提出可核對的操作步驟。 回覆需有來源、無資料時拒答、工具權限與超時。模型推論只是延遲的一段；索引和文件也占用 RAM 與 SSD。 技術起點：檢索 → LLM → 結構化工具 → 確認 / 日誌。驗收：來源正確、檢索召回、無證據拒答、工具權限、逾時、prefill / decode 與索引容量。

結帳／訂單核對

檢查餐盤或包裹中的物品，與訂單資料比對，將差異交由人員確認。 參考 Intel 零售 order-accuracy 管線；相似包裝、反光、重疊與未知 SKU 是主要限制。 技術起點：多角取像 → 偵測 + OCR → 訂單比對 → 人工複核。驗收：SKU 與數量正確率、相似包裝／遮擋、未知 SKU、OCR 欄位與人工複核率。

智慧安防攝影機

低功耗廣角攝影機先做影像校正，再產生區域入侵或人車事件。 參考 Kneron IP camera 與 Ambarella security 產品方向；需查低照度、魚眼變形、編碼及全天候溫度。 技術起點：ISP / 廣角校正 → 物件偵測 → 事件規則 → 告警。驗收：日夜事件召回、每小時誤報、廣角邊緣、編碼＋AI 並存、環溫及熱穩態。

姿態／動作分析

工作站以骨架關節評估動作，避免持續保存可辨識人臉的原始影片。 先定義關節誤差、遮擋和多人體相互影響；骨架不代表沒有個資風險。 技術起點：人員偵測 → 姿態估計 → 時間序列 → 動作事件。驗收：關節誤差、多人體遮擋、action window 延遲、隱私與失效處置。

無人機遠距追蹤

無人機在 120 m 拍攝距離，使用長焦雲台追蹤遠處巡檢車；先檢查有效像素與角速度，再決定追蹤更新率。 遠距不只看 FPS：物件實際尺寸、距離與 FOV 決定像素密度；大氣、震動、曝光、遮擋和地理定位誤差也要驗收。 技術起點：長焦 gimbal → IMU / 同步 → 目標 / 特徵 → 時序追蹤。驗收：30–120m 等實際距離的目標框／紋理 px、長焦抖動、霧／熱擾動、失鎖恢復。

無人機空拍建圖

無人機空拍工業區，利用相機／IMU／GNSS 估計位姿與尺度，再建立可核對的地圖。 相對深度不能直接當地理尺度。影像重疊、時間同步、GNSS／地面控制點與漂移是主要限制；離線建圖與飛行控制分開。 技術起點：相機 + IMU / GNSS → 位姿 / VIO → 深度 / 重建 → 地圖驗收。驗收：地面控制點／GNSS 對照、尺度與軌跡漂移、影像 overlap、定位失效及 map RAM。

無人機飛行避障

低速室內巡檢無人機用前向度量深度辨識管線與低矮障礙，按感知距離與制動能力設定速度。 飛行的垂直／水平速度與制動不同；本工具只是單方向保守起測。失效、飛控與安全分析需獨立驗證。 技術起點：Stereo / ToF → 運動補償 → 障礙距離 → 飛控限制。驗收：近遠距公尺誤差、最小障礙物、flight latency、制動可用距離與故障處置。

移動機器人空間感知

戶外配送機器人辨識近處路緣與遠處行人，融合相機、里程與度量感測維持可核對的空間位置。 移動相機需要區分本體運動與目標運動；近場避障、遠場語意與定位漂移採不同驗收尺度。 技術起點：相機 / LiDAR → 位姿 / SLAM → 深度融合 → 路徑規劃。驗收：近遠場誤差、最小障礙物、定位漂移、運動取像與感測器失效恢復。

車載遠距觀測

車載前向相機觀察遠處車輛與行人，檢查小目標縮圖尺寸和端到端延遲，供影片分析或研究原型。 此為車載感知規劃，不代表自駕／ADAS 認證。高速、反光、雨霧、鏡頭畸變與感測融合必須獨立驗收。 技術起點：前向相機 → 運動補償 → 偵測 / 深度 → 事件 / 研究控制。驗收：80m 等遠距目標縮圖後 px、車體震動、快門／曝光、P95 及失效告警。

YOLO + 物件追蹤

YOLOv8n/s/m 640 輸入作容量起測，接 ByteTrack 或其他 MOT。檢查 Conv、Resize、Concat、輸出解碼、NMS 與 INT8 校正。模型代際與 export 不可混用。

OCR

文字偵測與辨識是兩段工作；裁切數量決定額外負載。先驗證斜角、反光、字元尺寸與業務格式。

TAPIR / TAPNet

先固定 causal checkpoint、點數、輸入尺寸與 state。注意採樣、相關性運算、時序狀態及 GridSample 類匯出節點；實際圖以 export 為準。GPU 起測仍不能保證 Edge 即時。

CoTracker

online 以 chunk/window 處理，不等於零等待。點數、滑動視窗、attention 與狀態增加記憶體及延遲。加入此卡代表與既有模型並存；可移除 TAPIR 以比較替代。

SAM 2

encoder、prompt decoder 和 memory attention 需分別測試。A100 論文數據不能直接轉成 NPU 或 Jetson FPS。

運動補償／IMU 融合

用標定、IMU、global motion 或光流估計相機運動；rolling shutter 和時間戳偏差仍需驗證。

串流 ASR + VAD

指定語言、麥克風距離、噪音、喚醒詞與句尾偵測；衡量 WER 與 final transcript 延遲。

串流 TTS + AEC

指定第一段音訊延遲、語言、聲音與串流格式；回音消除與 barge-in 需要音訊回路驗證。

本地 RAG / Tool calling

embedding、reranking、文件索引與工具執行各有 RAM／延遲預算；不能只量 LLM decode tok/s。

Pose / Action 模型

從輕量 pose 起測，再依動作期限選時序分類。人物數、骨架點數、視角和時間窗會增加負載。

SLAM / VIO / GNSS 融合

先區分幾何 SLAM、learned 特徵／深度與導航控制。IMU timestamp、相機標定、回環與 GNSS／控制點決定尺度與漂移；深度模型無法取代全部定位。

深度與決策

深度色彩不等於公尺；決策模型也需要部署資源。

相對／公尺深度→本地／雲端決策

按情境查看重點

Depth Anything

本頁 DAC 依使用者定義對應 Depth Anything 系列。相對深度與 metric depth 分開；檢查 Resize、normalization、attention、輸出尺度。

VLM 分類器

從小型 VLM 起測，固定影像 token、上下文、量化與輸出長度。記錄首 token、完整回答延遲及峰值 RAM；勿用 detector FPS 估計。

Jev / RLCD Qwen 決策

依本工具需求，Jev 是以 RLCD + Qwen checkpoint 在本地做結構化決策；請指定參數規模、量化、runtime 和狀態預算。也可改為雲端 API，移除這個決策模型的本地運算負載，另驗證連線與服務延遲。

Stereo / ToF 深度

選雙目／ToF／RGB-D 感測路徑；焦距、baseline、同步與深度不確定性決定公尺精度。影像處理負載與裝置接入分別驗證。

本地 LLM / Strata

預設以 Strata 作 Qwen3.8-Flash-Next 的本地路徑，經相容 API 接 Agent。GPU expert cache、CPU/RAM 與 SSD embedding 分層；桌機結果不能當 Jetson benchmark。

距離分段誤差

在近／遠距分別指定絕對誤差上限，保留 95% 或最大誤差的驗收定義。這是需求，不是模型已達成。

按情境查看重點

遠距與移動取像

中心 pinhole 粗估 fx＝W / (2 tan(FOV/2))；物件寬 px≈fx × 實體寬／距離；相機角速度換成 px/s，再加目標運動。縮圖後紋理、曝光模糊、FOV、IMU 同步及長焦抖動共同限制 tracking。DLSS／插幀不增加實拍資訊。

相機與動作

用真實相機 FPS、影像平面速度、曝光、目標像素及模型縮放後尺寸評估。插幀不能補回未拍到的觀測。

FOV 與目標占比

定義水平 FOV、輸出高寬、目標框像素及縮圖後大小；寬視野降低同一目標的像素密度。

機身／雲台晃動

以 FOV 和角速度推算局部中心附近的像素位移；需要相機 timestamp、IMU 同步與快門型態。

語音回應與聲學

500 ms 可選首音訊或完整回覆；需包含 VAD、ASR、prefill、LLM、工具與 TTS，而非只看 decode。

遠距離與長焦取像

以 pinhole 中心近似估算目標像素：fx × 物件尺寸 ÷ 距離。長焦提高像素密度，也提高角速度造成的像素位移；實際還需標定與大氣／曝光驗證。

算子與版本

能匯出模型，不代表裝置能完整加速。

版本固定→編譯→查 CPU 回退→全管線量測

按情境查看重點

YOLO + 物件追蹤：部署查核

Conv / Resize / Concat / decode / NMS；固定 export、opset、shape、INT8 校正及 host NMS。 固定模型版本、export opset、SDK／driver，compile 後檢查 partition / fallback，量測完整管線。

OCR：部署查核

文字偵測＋辨識兩張圖；Resize / recurrent 或 attention 依 checkpoint；裁切數與動態寬度須查。 固定模型版本、export opset、SDK／driver，compile 後檢查 partition / fallback，量測完整管線。

TAPIR / TAPNet：部署查核

causal checkpoint、correlation / sampling、GridSample 類節點與外部 temporal state；實際圖為準。 固定模型版本、export opset、SDK／driver，compile 後檢查 partition / fallback，量測完整管線。

CoTracker：部署查核

online window / chunk、attention / Gather / sampling 與 state；window 等待時間加入 deadline。 固定模型版本、export opset、SDK／driver，compile 後檢查 partition / fallback，量測完整管線。

SAM 2：部署查核

image encoder / prompt decoder / memory attention 各自 compile 與 profile；確認 prompts 與 state shapes。 固定模型版本、export opset、SDK／driver，compile 後檢查 partition / fallback，量測完整管線。

Depth Anything：部署查核

Resize 語意、normalization、attention 與輸出尺度；relative / metric checkpoint 分開。 固定模型版本、export opset、SDK／driver，compile 後檢查 partition / fallback，量測完整管線。

VLM 分類器：部署查核

vision encoder / image tokens / LLM prefill / decode、KV cache；固定影像數、context 與量化。 固定模型版本、export opset、SDK／driver，compile 後檢查 partition / fallback，量測完整管線。

Jev / RLCD Qwen 決策：部署查核

RLCD Qwen checkpoint 的 attention / decode / cache / structured output；本地 backend 支援依該模型版本驗證。 固定模型版本、export opset、SDK／driver，compile 後檢查 partition / fallback，量測完整管線。

Stereo / ToF 深度：部署查核

Stereo rectification / disparity 或 ToF driver；先驗證標定同步與低紋理，非所有路徑都用 NPU。 固定模型版本、export opset、SDK／driver，compile 後檢查 partition / fallback，量測完整管線。

運動補償／IMU 融合：部署查核

IMU / global motion / warp、rolling shutter 與時間戳；GPU warp 與 CPU fusion 分別測。 固定模型版本、export opset、SDK／driver，compile 後檢查 partition / fallback，量測完整管線。

本地 LLM / Strata：部署查核

Strata 指定 commit / 量化／CPU 架構／GPU kernels；桌機 cache + host 分層與全駐留不同。 固定模型版本、export opset、SDK／driver，compile 後檢查 partition / fallback，量測完整管線。

串流 ASR + VAD：部署查核

VAD / encoder / decoder、streaming chunk 與跨 chunk state；Riva / QNN 不可互換當成已部署。 固定模型版本、export opset、SDK／driver，compile 後檢查 partition / fallback，量測完整管線。

串流 TTS + AEC：部署查核

decoder / vocoder、streaming chunk、音訊 buffer 與 AEC；測首音訊與完整播放。 固定模型版本、export opset、SDK／driver，compile 後檢查 partition / fallback，量測完整管線。

並存模型資源池

預設全部技術同時運行。記憶體＝系統＋Σ（共用權重＋每路 state × 路数／請求並行）。獨顯分開 RAM / VRAM；統一記憶體用總量。Strata host 取文件最低門檻與規劃驻留加其他 host 的較大值。預設 GB 是可覆寫規劃包絡，非 benchmark。GPU 時間＝Σ ms × Hz × 路数 ÷1000，只篩指定 profile 裝置，未測模型仍未知。

持續即時

同時驗收 FPS、P95 延遲、最舊影格年齡與丟幀率。串流可 pipeline，吞吐與延遲不互相等價。

多路相機

路數會提高解碼、ISP、記憶體搬移與推論負載；也要查 board CSI/USB/以太網、同步和驅動。

RAM 限制

設定可接受的實體 RAM 上限；實際可用量更少。模型載入成功不代表多路/長時運行不會 OOM。

模組廠採購分級

僅使用低／中／高等級；不是零售市價或美元估價。各平台預設分級僅為展示起點，請按同一 BOM 範圍、量產數量與供應商報價覆寫。先排除硬性限制；可選技術優先或採購優先，同分以較低等級排序。chip、SoM、載板及整機不可直接比較成本。

完全離線

所有必要推論須可本地部署；服務 API 不符合。離線批次與完全離線是不同概念。

整機功耗上限
